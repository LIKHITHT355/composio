🔍 Key Methodological Insight: The "Honesty Dip"

While Naive v1 produced seemingly higher exact-match scores by guessing generic defaults (e.g. assuming every app has an API key and is self-serve), it hallucinated APIs for CLI tools (Sherlock) and ignored sales gating (DealCloud). Agent v2 strictly refused to hallucinate without verbatim quotes, creating an initial conservative dip that Agent v3 & v4 systematically resolved through deterministic arbiter rules.
